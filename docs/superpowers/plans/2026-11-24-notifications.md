# هيكلة التنبيهات الجديدة (صفوت — 24 نوفمبر، بعد ميتنج 23 نوفمبر)

> «بعد ما نخلص نظبط اعدادات التنبيهات بالاستركشر الجديدة» — المرحلة 10 بعد مراحل الميتنج التسعة. PR لوحده. مفيش أي كتابة على الموقع.

## اللي فهمته

### 1) التنبيه = قاعدة بتتبني من الإعدادات (رسمة «إضافة تنبيه»)
- **تفاصيل التنبيه:** اسم التنبيه · **العنصر** (عهدة التشغيل، أعضاء الفريق، الأوردرات الرئيسية، الأوردرات الفرعية، المنتجات، الحسابات، طلبات الفريق،
  الرسايل، الذكاء الاصطناعي، المبتكرين) · **نوع التنبيه** (بيتغيّر حسب العنصر) · **الوضع** (بيتغيّر حسب النوع).
- **وقت الإرسال:** الوقت (الساعة 12) · التكرار: غير متكرر / كل 24 ساعة / كل 48 ساعة / أسبوعيًا / شهريًا / أيام محددة من الشهر.
- **تفاصيل الظهور** (3 اختيارات): «مدة محددة» (12 / 24 / 48 / 72 ساعة / أسبوع) · «حتى تغيير الوضع» ويختفي في نفس الوقت / بعد 4 / بعد 6 ساعات ·
  «حتى التحوّل لمقروء» ويختفي بعد ساعتين / 4 / 6 ساعات.
- **تفاصيل الإرسال:** قنوات الإرسال · المستلم = أدوار السيستم الحالية (أكتر من دور).
- **قالب الرسالة:** نص التنبيه.

### 2) الكتالوج — العنصر › النوع › الوضع (رسمة الجدول — قريتها كده، صحّح لو فيه غلط)
| العنصر | النوع | الأوضاع |
|---|---|---|
| عهدة التشغيل | الرصيد | إيداع · سحب · العهدة وصلت 200 ج.م |
| أعضاء الفريق | حالة | التقييم الشهري · لم يسجل حضور · بدء وقت إضافي · لم يسجل انصراف |
| | تحديث | تسجيل الحضور · تسجيل الانصراف · طلب إجازة · طلب سلفة · طلب فترة راحة · طلب خاص · طلب وقت إضافي |
| الأوردرات الرئيسية | حالة التأكيد | حالات التأكيد في السيستم (مؤكد بعربون · غير مؤكد …) |
| | حالة الأوردر | حالات الأوردر في السيستم (جاري التنفيذ · معلّق · جاهز للشحن …) |
| | حالة التأخير | متأخر · غير متأخر · قابل للتأخير |
| | تحديث | أوردر جديد · تعديل أوردر · حذف أوردر |
| الأوردرات الفرعية | حالة الأوردر الفرعي | حالاته في السيستم (مؤكد · جاهز للشحن من المبتكر للعميل …) |
| | حالة التأخير | متأخر · غير متأخر · قابل للتأخير |
| | تحديث | أوردر جديد · تعديل · حذف |
| المنتجات | حالة المنتج | الكمية نفدت · باقي 1 في المخزون · باقي 3 في المخزون |
| | تحديث | حذف منتج · إضافة دفعة منتجات · تحويل لمسودة · تعديل بيانات · نقل منتجات · إضافة / حذف / تعديل قسم |
| الحسابات | مصروفات · مرتبات · اشتراكات · إعلانات · حسابات المبتكرين · الحساب الفعلي | إيداع · سحب |
| طلبات الفريق | طلب إجازة · طلب سلفة · … كل أنواع الطلبات | طلبات جديدة · طلبات متأخرة |
| | تحديث | تعديل طلب · جاري العمل · في انتظار الرد · تم الحل |
| الرسايل | رسايل المبتكرين · رسايل العملاء · السوشيال ميديا | رسايل جديدة · رسايل متأخرة |
| الذكاء الاصطناعي | الميديا باير | أداء الحملات · حالة البيكسل · نشر بوست |
| | الديزاينر | آخر التريندات · بناء حملة |
| | المبرمج | تحديثات ووردبريس · مشاكل API · كفاءة أداء النظام |
| المبتكرين | حالة التصنيع | أوردرات متأخرة · قابلة للتأخير · مؤكدة جديدة · ملغية |
| | حسابات المبتكر | طلب سحب · تقفيل الحسابات |
| | تحديث | إضافة مبتكر · حذف مبتكر · تعديل بيانات · إضافة براند · نقل منتجات · حالة المبتكر |

### 3) بوب أب الجرس — أقسام رئيسية وتحتها فرعية (فلاتر)
- **بيتشال:** النظام · تقارير المهام (بتبقى «التقارير اليومية») · الفريق القديم · المخزن · مهام.
- **التقارير اليومية.**
- **مساعدين الذكاء الاصطناعي:** الكل · مقروء · غير مقروء.
- **خدمة العملاء:** الكل · متأخر · غير مؤكدة · في انتظار الرد.
- **متابعة المبتكرين:** الكل · متأخر · قابلة للتأخير · مؤكد.
- **العمليات والشحن:** الكل · جاهز للشحن للمخزن · جاهز للشحن للعميل (وتحت كل أوردر هيروح المخزن ولا هيطلع على طول، ويتفتح في بوب أب ويتعمل له بوليصة) ·
  مرتجع يحتاج فحص · العهدة (لما تقل عن 200 ج.م: «الحق الفلوس قربت تخلص») · استوك قرب يخلص.
- **الحسابات:** المصروفات · طلبات السحب · حساب المبتكرين (تنبيه قبل ميعاد التقفيل) · المرتبات (قبلها بيومين) · الاشتراكات (قبل ميعادها) · العهدة · الحركة المالية (ملخص).
- **الفريق:** الحضور والانصراف (ماسجّلش حضور في ميعاده، نسي يسجل خروج، خلص وقت العمل وجه وقت إضافي، وبعد ساعة «فلان متأخر») · الطلبات (كل الأنواع، اللي
  طلبها أو المطلوبة منه، والمتأخرة «حالتها ماتغيّرتش») · التقييم (قبل ميعاد التقييم و«جه وقت التقييم») — وترتيب من الأحدث للأقدم أو العكس.
- **الرسايل:** من العملاء · من المبتكرين · تعليقات.
- **الجديد بنقطة خضرا**، والقديم اللي اتشاف وعدّى عليه وقته النقطة بتتشال.
- **كل مساعد ذكاء اصطناعي** ليه تنبيهات دوره بنفس الشكل الجديد.

### 4) اللي هيتعدّل معاه
التنبيهات حسب الدور (الماتريكس الحالية) · تقارير المهام → التقارير اليومية · تنبيهات المساعدين — كله على الهيكلة الجديدة عشان كله يمشي مع بعض.

## إجابات صفوت (24 نوفمبر)
- **مين يعدّل:** الأدمن من الإعدادات بس — الأقسام الرئيسية والفرعية والتنبيهات لكل الأدوار؛ العضو بيشوف اللي يخصّه في الجرس.
- **التنبيهات الحالية** (الأنواع وماتريكس الأدوار والتصعيد وساعات الهدوء والتقارير المجمّعة وتنبيهات المساعدين): **تتشال ونبدأ من أمثلته بس**.
- **عهدة العمليات** = حساب «أوبريشن» في الحسابات (رصيده أقل من 200 ج.م).
- **القنوات:** الجرس بس دلوقتي — الإيميل والواتساب في الفورم مقفولين لحد ما يتشغّلوا من الإعدادات.
